# Computer Architecture Lab Codes (Lab 3 to Lab 9)

## Description

This repository contains VHDL implementations of digital circuits and computer architecture components developed during a Computer Architecture laboratory course (Labs 3-9). The codes cover fundamental topics from basic memory units to a complete 8-bit CPU implementation.

## Key Features

- Synthesizable VHDL code
- Comprehensive testbenches for each module
- FSM-based control units
- Reset functionality for all modules
- Memory initialization capabilities
- Ready/valid handshake signals where applicable

## Simulation

Each module can be simulated using any VHDL simulator (ModelSim, GHDL, Vivado Simulator). Testbenches include clock generation, reset sequences, and multiple test cases covering normal operation, edge cases, and error conditions.
